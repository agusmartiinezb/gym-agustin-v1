# Gym Agustín

App personal de seguimiento de gimnasio. Rutina 3 días/semana (Día A: pecho/hombro/tríceps, Día B: piernas, Día C: espalda/bíceps) + cardio.

- React + Vite + Tailwind (CDN)
- Persistencia en localStorage (clave `gym_v1`)
- Export/Import JSON para backup
- PWA instalable en el celu

## Uso

- Instalar dependencias: `npm install`
- Desarrollo: `npm run dev`
- Build: `npm run build`

## Deploy

Push a GitHub → import en Vercel → deploy automático.
